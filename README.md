# Café Apante

Sistema de Caja e Inventario para la MYPYME **Café Apante** (Nicaragua): caja con efectivo y depósito por QR,
inventario en libras, clientes, impuestos DGI, dashboard con proyecciones, notificaciones y acceso por roles.

```
cafe-apante/
  client/   Interfaz web (React + Tailwind CSS)
  server/   API (Express) sobre SQL Server
  shared/   Reglas de negocio compartidas (IVA, retención, vuelto, semáforo, proyección)
```

Instalación, uso, impuestos, respaldos y seguridad: ver [cafe-apante/README.md](cafe-apante/README.md).

> Este repositorio no contiene credenciales ni datos del negocio. Las contraseñas temporales de los usuarios
> iniciales se generan al azar en cada instalación.
